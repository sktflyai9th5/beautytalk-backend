# 메이크업 경로 프롬프트 — 대체 필요

`system_prompt.txt` 는 **임시본이다.**

어댑터(`iouty/qwen3vl-makeup-qwen3vl_augmented`)에는 시스템 프롬프트가 들어 있지
않다. 저장소에 있는 파일은 LoRA 가중치와 토크나이저뿐이고, README 는 Unsloth
기본 문구다. 파인튜닝 모델은 보통 **학습 때 쓴 시스템 프롬프트**를 그대로 줘야
성능이 나오므로, 학습에 쓴 원문을 받아 이 파일을 통째로 덮어써야 한다.

지금 들어 있는 내용은 립 경로 프롬프트(`../lip/system_prompt.txt`)의 원칙 —
시각장애인 대상, TTS 낭독, 사용자 기준 좌우, 없는 결함 만들지 않기 — 을 얼굴
전체로 넓혀 쓴 것이다. 형식은 맞지만 학습 분포와 일치한다는 보장은 없다.

교체는 이 파일만 바꾸면 된다. 서버 재시작 외에 다른 작업은 없다.

few-shot 예시가 필요하면 `fewshot/fewshot.json` 을 립 경로와 같은 형식으로 두면
자동으로 실린다(`routes.py` 참고). 지금은 없어서 예시 없이 나간다.
